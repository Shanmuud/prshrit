# CSS 2103 tagging rubric

Use the dominant technique requested by the question as the primary topic and
module. Preserve every subpart in the question text; list secondary techniques
in the subtopic and method when a question spans several techniques.

| Module | Course material | Typical tags |
| --- | --- | --- |
| 1 | Introduction to Data Analytics | Data types, analytics workflow, descriptive/predictive/prescriptive analytics |
| 2 | Data exploration | Descriptive statistics, box plots, skewness, correlations, group comparisons |
| 3 | Data preparation and hypothesis testing, both decks | Binning, normalization, data reduction, Z/t/chi-square tests, two-way ANOVA |
| 4 | Frequent itemsets and association rules | Apriori, hash pruning, FP-growth, vertical TID sets, closed/maximal patterns, rule evaluation |
| 5 | Time-series forecasting | Components, moving averages, forecast errors, exponential smoothing, Holt, ARIMA |

One-way ANOVA appears in module 2's relationship-analysis material. Two-way ANOVA
belongs to module 3's hypothesis-testing deck. Paper questions mixing descriptive
statistics and relationship analysis stay in module 2. Binning belongs to module
3 even when the question also asks for a histogram.

Method labels name techniques rather than results. Approach text gives one to
three sentences of steps or symbolic formulas, without calculated statistics,
final forecasts, mined itemsets or significance conclusions. Preserve missing
parameter and inconsistent-data caveats where the source requires them.

CSS 2103 has no difficulty, reason or LeetCode tags under A4.1. Do not apply the
DSA difficulty rubric to this subject. Paper metadata comes from the PDF and
isolated scrape manifest; missing CO/cognitive labels remain null.
